This occurs DURING page extraction in text lanr 

OCR and parser generator processes the input document and sends the initial results to the Manager. The Manager then forwards these results to the Scan module for analysis. if the forward result is pdf stem data scan module skip calling engine and directly pass to pdf file output writer.


During this analysis, the scan module   call another generator [engine ]and  consume that generator output and write the retrn  result  from engine to temp file. and  after finish consuming engine generator check  the error by reading that temp file if an error detected the Scan module return the response and ask  manager to provide error region   region inside the logical PDF (lpdf) and the specific glyph information  from the Manager. The Manager retrieves this data and sends the glyph and corresponding PDF line back to the Scan module. The Scan module then invokes  the PDF-to-SVG module to perform glyph matching. Once the Glyph Matching module processes the request and returns the matched results to scan , the Scan module replaces the erroneous line with the corrected output inside previous tmp file  and call output writer. If no error is detected, the Sca  modules  directly call next to   Manager to parse again andFinally, the Scan module call  the final output  pdf writer
