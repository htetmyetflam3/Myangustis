(က)  ကိုယ်အဂါအစိတ်အပိုင်း[20]ဆိုသည်မှာ လူ၏ခန္ဓာကိုယ်နှင့်ယင်းခန္ဓာကိုယ် ဖွဲ့စည်းမှုတွင် 
ပါဝင်ေသာ ကိုယ်အဂါအစိတ်အပိုင်းတစ်ခုခုကို ဆိုသည်။ 
( ခ ) ေသဆုံးသူ[20]ဆိုသည်မှာ အေကာင်းတစ်ခုခုေကာင့် လူ၏ ဦးေနှာက်လုပ်ငန်းများအားလုံး 
လုံးဝရပ်စဲသွား၍ေသာ်လည်းေကာင်း၊ ေသွးလည်ပတ်မှုလုပ်ငန်းများအားလုံး လုံးဝရပ်စဲ 
သွား၍ေသာ်လည်းေကာင်း သက်ဆိုင်ရာဆရာဝန်များက ေသဆုံးေကာင်း အတည်ြပုြခင်း 
ခံရသူကိုဆိုသည်။ 
( ဂ ) ကိုယ်အဂါအစိတ်အပိုင်းလှူဒါန်းသူ ဆိုရာတွင် ကိုယ်အဂါအစိတ်အပိုင်းများကို 
ဆန္ဒအေလျာက်အခမဲ့ခွင့်ြပုလှူဒါန်းသည့်  ေအာက်ပါပုဂ္ဂိုလ်တို့ ပါဝင်သည်- 
(၁) မိမိ၏ ကိုယ်အဂါအစိတ်အပိုင်းတစ်ခုခုကို အြခားသူတစ်ဦးတစ်ေယာက်၏ 
ခန္ဓာကိုယ်တွင် အစားထိုးအသုံးြပုနိုင်ေရးအတွက် ထုတ်ယူရန် ခွင့်ြပုေသာ 
အသက် (၁၈) နှစ် ြပည့်ပီး စိတ်ကျန်းမာေရးေကာင်းမွန်သည့် သက်ရှိထင်ရှားရှိသူ၊ 
(၂)  မိမိေသဆုံးပီးေနာက် မိမိ၏ ကိုယ်အဂါအစိတ်အပိုင်းတစ်ခုခုကို ထုတ်ယူ၍ 
လိုအပ်သလို အသုံးြပုနိုင်ေရးအတွက် သက်ရှိထင်ရှားရှိစဉ်ကတည်းက ကိုတင် 
ဆန္ဒြပုထားသူ၊ 
(၃)  ပုဒ်မခွဲငယ် (၂) အရ ကိုတင်ဆန္ဒြပုထားြခင်းမရှိသည့် ေသဆုံးသူ၏ ကိုယ်အဂါ 
အစိတ်အပိုင်းတစ်ခုခုကို ထုတ်ယူ၍ လိုအပ်သလို အသုံးြပုရန် ခွင့်ြပုသည့် 
ကျန်ရစ်သူဇနီး၊ ခင်ပွန်း၊ သားသမီး၊ မိဘ၊ ညီအစ်ကို ေမာင်နှမများ၊ ယင်းတို့ 
တစ်ဦးတစ်ေယာက်မျှမရှိ၍ ယင်းတို့၏ကိုယ်စားခွင့်ြပုေသာ ေဆွမျိုးသားချင်း 
တစ်ဦးဦး။

(ဃ)  အရည်အေသွးစစ်ေဆးြခင်း[20]ဆိုသည်မှာ ကိုယ်အဂါအစိတ်အပိုင်းလှူဒါန်းသူ၏ ကိုယ်အဂါ 
အစိတ်အပိုင်းသည် အစားထိုး ကုသြခင်းြပုနိုင်သည့် အရည်အေသွး ရှိ မရှိ သတ်မှတ်ချက် 
များနှင့်အညီ စစ်ေဆးြခင်းကို ဆိုသည်။ 
( င )  လက်ခံေရးဌာန[20]ဆိုသည်မှာ  ကိုယ်အဂါအစိတ်အပိုင်းလှူဒါန်းသူ၏ ကိုယ်အဂါ အစိတ်အပိုင်း 
များကို သတ်မှတ်ချက်နှင့်အညီ အရည်အေသွးစစ်ေဆး၍ လက်ခံြခင်း၊ သိုေလှာင်ြခင်း 
နှင့်ထုတ်ေပးြခင်းြပုသည့်ဌာနကို ဆိုသည်။ 
( စ ) သိုေလှာင်ြခင်း ဆိုသည်မှာ ကိုယ်အဂါအစိတ်အပိုင်းလှူဒါန်းသူ၏ ကိုယ်အဂါအစိတ် 
အပိုင်းကို ထုတ်ယူပီး အစားထိုးကုသရန်ြဖစ်ေစ၊ ပညာသင်ကားရန်ြဖစ်ေစ၊ သုေတသန 
ြပုရန်ြဖစ်ေစ လိုအပ်သည့် အချိန်တွင် အသင့်ရှိေစေရးအတွက် သတ်မှတ်ချက်များနှင့် 
အညီ လက်ခံေရးဌာနက ထိန်းသိမ်းထားြခင်းကို ဆိုသည်။ 
(ဆ)  ထုတ်ေပးြခင်း ဆိုသည်မှာ သိုေလှာင်ထားေသာ ကိုယ်အဂါအစိတ်အပိုင်းကို အစားထိုး 
ကုသရန်ြဖစ်ေစ၊ ပညာသင်ကားရန်ြဖစ်ေစ၊ သုေတသနြပုရန်ြဖစ်ေစ သတ်မှတ်ချက်များ 
နှင့်အညီ လက်ခံေရးဌာနက ထုတ်ေပးြခင်းကို ဆိုသည်။ 
( ဇ ) အစားထိုးကုသြခင်း[20]ဆိုသည်မှာ အေကာင်းတစ်ရပ်ရပ်ေကာင့် ကိုယ်အဂါအစိတ်အပိုင်း 
တစ်ခုခုပျက်စီးဆုံးရှုံးရသူ၏ ပျက်စီးဆုံးရှုံးသွားေသာ ကိုယ်အဂါအစိတ်အပိုင်းကို 
လှူဒါန်းသူ၏ ကိုယ်အဂါအစိတ်အပိုင်းြဖင့် အစားထိုးရန် ခွဲစိတ်ြခင်းြဖင့်ေသာ်လည်းေကာင်း၊ 
အြခားတစ်နည်းနည်းြဖင့်ေသာ်လည်းေကာင်း ကုသြခင်းကိုဆိုသည်။ 
( စျ )  အသိအမှတ်ြပုလွှာ[20]ဆိုသည်မှာ ကိုယ်အဂါအစိတ်အပိုင်းလှူဒါန်းသူအား လက်ခံေရး 
ဌာနက ထုတ်ေပးသည့် ကိုယ်အဂါအစိတ်အပိုင်း လှူဒါန်းြခင်းဆိုင်ရာ အသိအမှတ်ြပု 
လက်မှတ်ကို ဆိုသည်။ 
(ည) ကိုယ်အဂါအစိတ်အပိုင်းထုတ်ယူခွင့်ရှိသူ ဆိုသည်မှာ ကိုယ်အဂါအစိတ်အပိုင်း လှူဒါန်း 
သူထံမှ ကိုယ်အဂါအစိတ်အပိုင်းကိုထုတ်ယူရန် ကျန်းမာေရးဝန်ကီးဌာန၏ အခွင့်အာဏာ 
အပ်နှင်းြခင်းခံရသူကို ဆိုသည်။ 
( ဋ )  ကိုယ်အဂါအစိတ်အပိုင်းထုတ်ယူြခင်း[20]ဆိုသည်မှာ ကိုယ်အဂါအစိတ်အပိုင်းထုတ်ယူခွင့်ရှိ 
သူက သတ်မှတ်ချက်များနှင့်အညီ ထုတ်ယူြခင်းကို ဆိုသည်။ 
( ဌ )  ေကာ်မတီ[20]ဆိုသည်မှာ ဤဥပေဒပုဒ်မ ၄ အရ ဖွဲ့စည်းသည့် ကိုယ်အဂါအစိတ်အပိုင်း 
လှူဒါန်းြခင်းဆိုင်ရာ ကီးကပ်မှုေကာ်မတီကို ဆိုသည်။

အခန်း (၂) 
ရည်ရွယ်ချက်များ 
၃။  ဤဥပဒေ၏ ရည်ရွယ်ချက်များမှာ အောက်ပါအတိုင်း ဖြစ်သည်- 
(က)  ကိုယ်အဂါအစိတ်အပိုင်း အစားထိုးကုသမှုကို ကျယ်ကျယ်ပြန့်ပြန့်ဆောင်ရွက်နိုင်ခြင်းဖြင့် 
ကိုယ်အဂါအစိတ်အပိုင်း အစားထိုးကုသမှုခံယူရမည့်သူများ၏အသက်ကို ကယ်တင်နိုင်ရန်၊ 
( ခ )  ကိုယ်အဂါအစိတ်အပိုင်းချွတ်ယွင်း၍ မသန်မစွမ်းဖြစ်သူများအား ကိုယ်အဂါအစိတ်အပိုင်း 
အစားထိုးကုသပေးနိုင်ခြင်းဖြင့် ပြန်လည်သန်စွမ်းလာစေရန်၊ 
( ဂ ) ကိုယ်အဂါအစိတ်အပိုင်း အစားထိုးကုသရေးလုပ်ငန်းများနှင့်သက်ဆိုင်သော သုတေသန 
လုပ်ငန်းနှင့်ပညာသင်ကားရေးလုပ်ငန်းများကို ဆောင်ရွက်နိုင်ရန်၊ 
(ဃ) ပြည်သူလူထုအတွင်း ကိုယ်အဂါအစိတ်အပိုင်းလှူဒါန်းသူများ တိုးပွားလာစေရေးအတွက် 
ဆောင်ရွက်နိုင်ရန်၊ 
( င )  ကိုယ်အဂါအစိတ်အပိုင်း အစားထိုးကုသရေးတွင် အစိုးရဌာန၊ အဖွဲ့အစည်းများ၊ 
အပြည်ပြည်ဆိုင်ရာအဖွဲ့အစည်းများ၊ ပြည်တွင်းပြည်ပမှ အစိုးရမဟုတ်သော အဖွဲ့အစည်းများ၊ 
ကုမ္ပဏီများ၊ ပုဂ္ဂိုလ်များ၏ အကူအညီရယူ၍ ပူးပေါင်းဆောင်ရွက်နိုင်ရန်။ 
အခန်း (၃)[20]
ကော်မတီဖွဲ့စည်းခြင်းနှင့် ယင်းကော်မတီ၏ လုပ်ငန်းတာဝန်များ[20]
၄။ (က) ပြည်ထောင်စုအစိုးရအဖွဲ့သည် ကိုယ်အဂါအစိတ်အပိုင်း လှူဒါန်းခြင်းဆိုင်ရာ ကီးကပ်မှု 
ကော်မတီကို အောက်ပါအတိုင်း ဖွဲ့စည်းရမည် - 
  (၁) ပြည်ထောင်စုဝန်ကီး၊ ကျန်းမာရေးဝန်ကီးဌာန  ဥက္ကဋ္ဌ 
  (၂) သက်ဆိုင်ရာအစိုးရဌာန၊ အဖွဲ့အစည်းများ၏   အဖွဲ့ဝင် 
   အကီးအမှူးနှင့် ကိုယ်စားလှယ် (၅) ဦး 
  (၃) သင့်လျော်သော ကျွမ်းကျင်သူပညာရှင် (၁၇) ဦး   အဖွဲ့ဝင် 
  (၄) ဥက္ကဋ္ဌက တာဝန်ပေးအပ်သူ  အတွင်းရေးမှူး 
( ခ )  ပုဒ်မခွဲ (က) အရ ဖွဲ့စည်းရာတွင် လိုအပ်ပါက အဖွဲ့ဝင်များအနက်မှ သင့်လျော်သည့် 
ပုဂ္ဂိုလ်များကို ဒုတိယဥက္ကဋ္ဌနှင့်တွဲဖက်အတွင်းရေးမှူးများအဖြစ် သတ်မှတ်တာဝန် 
ပေးအပ်နိုင်သည်။  
၅။ ကော်မတီ၏ လုပ်ငန်းတာဝန်များမှာ အောက်ပါအတိုင်းဖြစ်သည်- 
(က)  ကိုယ်အဂါအစိတ်အပိုင်း လှူဒါန်းခြင်းဆိုင်ရာလုပ်ငန်းများကို ထိရောက်အောင်မြင်စွာ 
အကောင်အထည်ဖော်ဆောင်ရွက်နိုင်ရေးအတွက် မူဝါဒများ ချမှတ်ခြင်း၊

အစိတ်အပိုင်းကို လှူဒါန်းေစြခင်း မြပုရ။ 
၁၉။ မည်သူမျှ ကိုယ်အဂါအစိတ်အပိုင်းကို လှူဒါန်းြခင်းြပုရန်ဆန္ဒမရှိသူထံမှ ကိုယ်အဂါအစိတ်အပိုင်း 
တစ်ခုခုကို ထုတ်ယူြခင်း၊ ယင်းသို့ ထုတ်ယူရန် ခိမ်းေြခာက်ြခင်း၊ အနိုင်အထက်ြပုြခင်း သို့မဟုတ်

တစ်ခုခုကို လှူဒါန်းသူ၏ သေဘာတူညီချက်မရရှိဘဲ ထုတ်ယူြခင်း၊ ယင်းသို့ ထုတ်ယူရန် တိုက်တွန်းြခင်း၊

၂၁။  မည်သူမျှ ကိုယ်အဂါအစိတ်အပိုင်း လှူဒါန်းသူများ မှတ်ပုံတင်စာရင်းပါ ေရးသွင်းထားချက်များကို 
မရိုးမေြဖာင့်ေသာသေဘာြဖင့်  ြဖည့်စွက်ြခင်း၊  ြပင်ဆင်ြခင်း သို့မဟုတ် ပယ်ဖျက်ြခင်းမြပုရ။

၂၃။  မည်သူမဆို ပုဒ်မ ၁၇ ပါ တားြမစ်ချက်ကို ေဖာက်ဖျက်ကျူးလွန်ေကာင်း ြပစ်မှုထင်ရှားစီရင် 
ြခင်းခံရလျှင် ထိုသူကို အနည်းဆုံး တစ်နှစ်မှ အများဆုံးသုံးနှစ်အထိ ေထာင်ဒဏ်ချမှတ်ရမည့်အြပင် 
ေငွဒဏ်လည်း ချမှတ်ရမည်။ 
၂၄။  မည်သူမဆို ပုဒ်မ ၁၈၊ ပုဒ်မ ၁၉ နှင့် ပုဒ်မ ၂၀ တို့ပါ တားြမစ်ချက်တစ်ရပ်ရပ်ကို ေဖာက်ဖျက် 
ကျူးလွန်ေကာင်း ြပစ်မှုထင်ရှားစီရင်ြခင်းခံရလျှင် ထိုသူကို အနည်းဆုံး ေြခာက်လမှ အများဆုံး 
သုံးနှစ်အထိ ေထာင်ဒဏ်ချမှတ်ရမည့်အြပင် ေငွဒဏ်လည်း ချမှတ်ရမည်။ 
၂၅။  မည်သူမဆို ပုဒ်မ ၂၁ ပါတားြမစ်ချက်ကို ေဖာက်ဖျက်ကျူးလွန်ေကာင်း ြပစ်မှုထင်ရှားစီရင်ြခင်း 
ခံရလျှင် ထိုသူကို နှစ်နှစ်ထက်မပိုေသာ ေထာင်ဒဏ်ြဖစ်ေစ၊ ကျပ်တစ်သိန်းထက်မပိုေသာ ေငွဒဏ်ြဖစ်ေစ 
ချမှတ်ရမည်။ 
၂၆။  မည်သူမဆို ပုဒ်မ ၂၂ ပါ တားြမစ်ချက်တစ်ရပ်ရပ်ကို ေဖာက်ဖျက်ကျူးလွန်ေကာင်း ြပစ်မှုထင်ရှား 
စီရင်ြခင်းခံရလျှင် ထိုသူကို သုံးနှစ် ထက်မပိုေသာ ေထာင်ဒဏ်ြဖစ်ေစ၊ ကျပ်နှစ်သိန်းထက် မပိုေသာ

(က)  အစိုးရဝန်ထမ်း မဟုတ်ေသာ ေကာ်မတီဝင်များအတွက် သတ်မှတ်သည့် ချီးြမှင့်ေငွနှင့် 
ေကာ်မတီ၏ အသုံးစရိတ်များကို ကျခံရမည်။ 
 ( ခ )  ေကာ်မတီ၏ ရုံးလုပ်ငန်းများကို တာဝန်ယူေဆာင်ရွက်ရမည်။ 
၂၉။  ဤဥပေဒပါ ြပဋ္ဌာန်းချက်များအရ သေဘာရိုးြဖင့် ေဆာင်ရွက်ေသာ တာဝန်ရှိသူတို့အား ြပစ်မှုေကာင်း 
အရြဖစ်ေစ၊ တရားမေကာင်းအရြဖစ်ေစ တရားစွဲဆိုခွင့်မရှိေစရ။  
၃၀။  ဤဥပေဒပါ ြပဋ္ဌာန်းချက်များကို အေကာင်အထည်ေဖာ် ေဆာင်ရွက်နိုင်ေရးအတွက် - 
(က)  ကျန်းမာေရးဝန်ကီးဌာနသည် လိုအပ်ပါက နည်းဥပေဒများ၊ စည်းမျဉ်းစည်းကမ်းများကို 
ြပည်ေထာင်စုအစိုးရအဖွဲ့၏ သေဘာတူညီချက်ြဖင့် ထုတ်ြပန်နိုင်သည်။ 
( ခ )  ေကာ်မတီနှင့် ကျန်းမာေရးဝန်ကီးဌာနတို့သည် လိုအပ်ေသာ အမိန့်ေကာ်ြငာစာ၊ 
အမိန့်၊ ညွှန်ကားချက်နှင့် လုပ်ထုံးလုပ်နည်းများကို ထုတ်ြပန်နိုင်သည်။ 
၃၁။  ကိုယ်အဂါအစိတ်အပိုင်းလှူဒါန်းြခင်းဆိုင်ရာ ဥပေဒ (နိုင်ငံေတာ်ေအးချမ်းသာယာေရးနှင့် 
ဖွံ့ဖိုးေရးေကာင်စီဥပေဒအမှတ် ၁/၂၀၀၄)ကို ဤဥပေဒြဖင့် ရုပ်သိမ်းလိုက်သည်။
