Page numbers are physical PDF pages (1-based), not printed book pages.

These 14 numbers are two-byte font glyph IDs, not Unicode code points or
keyboard bytes. A glyph may correspond to several Unicode code points;
different glyph shapes may also correspond to the same Unicode character.
The readings below are provisional draft values. 00EF, 00F0, 00F1 and
00F7 are source-context order slots; the other readings use the font GSUB
candidates. The draft reorders leading visual slots before the word reading.

Counts refer only to matching reference-font runs in the first 200 PDF
pages, before ToUnicode. The words below are examples, not a complete list.
Raw sequences are the actual font GIDs in visual stream order. Wider windows
and candidate origins are in zawcode-order-evidence.json.
